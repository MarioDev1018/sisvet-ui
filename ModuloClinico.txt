# **SISVET-CLINIC — Implementación del módulo Clinical**

## **1. Contrato arquitectónico y funcional**

La implementación seguirá la estructura de paquetes acordada:

`com.donkan.sisvetclinic.modules.clinical`

Se conservarán las tres divisiones principales:

- domain: entidades clínicas, estados y reglas propias del dominio.
- service: puertos de entrada y salida, servicios, DTO y workflows.
- infrastructure: controladores REST, persistencia SQL Server, tareas programadas y comunicación con Commercial.

El módulo formará parte del mismo proyecto Spring Boot que Commercial, Finance y Notification. No se creará una segunda aplicación.

### **Reglas obligatorias identificadas**

Del SRS consolidado se desprenden estas restricciones que deben trasladarse al código:

| Regla | Implementación requerida                                                                      |
| ----- | --------------------------------------------------------------------------------------------- |
| RN-02 | Cada mascota debe pertenecer a un propietario existente.                                      |
| RN-03 | Impedir citas superpuestas de un mismo profesional.                                           |
| RN-04 | Respetar la secuencia de estados de atención.                                                 |
| RN-05 | No iniciar una atención sin llegada registrada.                                               |
| RN-06 | No cerrar una atención clínica sin diagnóstico e indicaciones.                                |
| RN-07 | No finalizar una atención con peluquería pendiente.                                           |
| RN-08 | Recordatorios automáticos únicamente para citas confirmadas que cumplan el plazo establecido. |
| RN-09 | Solo el veterinario puede alterar la prioridad clínica de una urgencia.                       |
| RN-10 | Prescribir tratamientos no debe generar ventas ni modificar existencias.                      |

También incorporaré las dos piezas cuya ausencia detectamos en el diagrama: persistencia de FollowUp y una representación comprobable del cierre clínico.

El SAD V2.0, fechado el 14 de noviembre de 2026, advierte que el esquema clínico completo todavía no existe en la base SQL Server verificada. Por tanto, además de Java, es necesario definir las tablas clínicas y sus restricciones. No sería correcto presentar una implementación como funcional sobre la base actual sin resolver ese punto.

### **Criterios técnicos**

Utilizaré Java 21, Spring Boot 3, Spring JDBC y SQL Server para esta implementación. Java 21 y Spring Boot 3 son decisiones de implementación para el código mostrado, no versiones que haya podido verificar en el pom.xml existente, porque ese archivo no está entre los adjuntos.

Los contratos de dominio no dependerán de Spring, SQL ni clases de controladores. Los servicios de aplicación coordinarán las reglas y las transacciones. Los adaptadores realizarán las consultas a SQL Server.

La integración con Notification utilizará su contrato NotificationUseCase, sin copiar el servicio de notificaciones dentro de Clinical. Para que el sistema completo arranque con esa integración, dicho contrato deberá tener una implementación Spring disponible en el módulo Notification.

Hay una limitación adicional: se ha adjuntado código Java de la versión Swing y los diagramas comerciales, pero no el código fuente Spring Boot actual de Commercial ni su configuración de seguridad. Las integraciones con esos componentes deben respetar los contratos aquí definidos, pero no puedo certificar su compatibilidad binaria con clases que no he recibido.

### **2.13. ClinicalAttention.java**

Esta clase conserva comportamiento mutable porque implementa el patrón State y debe cambiar su estado durante una atención.

```
package com.donkan.sisvetclinic.modules.clinical.domain;

import com.donkan.sisvetclinic.modules.clinical.domain.state.*;
import java.time.LocalDateTime;

public class ClinicalAttention {

    private long id;
    private final long petId;
    private String type;
    private Integer priority;
    private String urgencyDescription;
    private Long priorityAssignedBy;
    private AttentionState state;
    private LocalDateTime arrivedAt;
    private boolean requiresGrooming;
    private boolean clinicalClosed;
    private Long consultationId;

    public ClinicalAttention(
        long id,
        long petId,
        String type,
        Integer priority,
        String urgencyDescription,
        Long priorityAssignedBy,
        String state,
        LocalDateTime arrivedAt,
        boolean requiresGrooming,
        boolean clinicalClosed,
        Long consultationId
    ) {
        this.id = id;
        this.petId = petId;
        this.type = type;
        this.priority = priority;
        this.urgencyDescription = urgencyDescription;
        this.priorityAssignedBy = priorityAssignedBy;
        this.state = AttentionStates.fromName(state);
        this.arrivedAt = arrivedAt;
        this.requiresGrooming = requiresGrooming;
        this.clinicalClosed = clinicalClosed;
        this.consultationId = consultationId;
    }

    public long getId() { return id; }
    public void setId(long id) { this.id = id; }

    public long getPetId() { return petId; }
    public String getType() { return type; }
    public Integer getPriority() { return priority; }
    public String getUrgencyDescription() { return urgencyDescription; }
    public Long getPriorityAssignedBy() { return priorityAssignedBy; }
    public String getStatus() { return state.getName(); }
    public LocalDateTime getArrivedAt() { return arrivedAt; }
    public boolean isRequiresGrooming() { return requiresGrooming; }
    public boolean isClinicalClosed() { return clinicalClosed; }
    public Long getConsultationId() { return consultationId; }

    public void markArrived(LocalDateTime at, boolean grooming) {
        if (arrivedAt != null) {
            throw new IllegalStateException(
                "La llegada ya fue registrada"
            );
        }

        arrivedAt = at;
        requiresGrooming = grooming;
    }

    public void registerUrgency(String description) {
        if (description == null || description.isBlank()) {
            throw new IllegalArgumentException(
                "Describa la urgencia"
            );
        }

        if (priority != null) {
            throw new IllegalStateException(
                "Solo el veterinario puede modificar la valoración clínica"
            );
        }

        urgencyDescription = description;
        type = "URGENCY";
    }

    public void assignPriority(int value, long veterinarianId) {
        if (urgencyDescription == null) {
            throw new IllegalStateException(
                "No existe una urgencia registrada"
            );
        }

        if (value < 1 || value > 5) {
            throw new IllegalArgumentException(
                "Prioridad entre 1 y 5"
            );
        }

        priority = value;
        priorityAssignedBy = veterinarianId;
    }

    public void setConsultationId(long id) {
        consultationId = id;
    }

    public void setClinicalClosed() {
        clinicalClosed = true;
    }

    public void changeState(AttentionState newState) {
        state = newState;
    }

    public void advance() {
        state.advance(this);
    }
}
```

### **3.2. AttentionStates.java**

```
package com.donkan.sisvetclinic.modules.clinical.domain.state;

public final class AttentionStates {

    private AttentionStates() {}

    public static AttentionState fromName(String name) {
        return switch (name) {
            case "EN_ESPERA" -> new WaitingState();
            case "ATENDIENDOSE" -> new InProgressState();
            case "EN_BANO" -> new BathingState();
            case "EN_PELUQUERIA" -> new GroomingState();
            case "LISTO_RECOJO" -> new ReadyForPickupState();
            case "ATENDIDO" -> new PickedUpState();

            default -> throw new IllegalArgumentException(
                "Estado de atención desconocido: " + name
            );
        };
    }
}
```

### **3.3. WaitingState.java**

```
package com.donkan.sisvetclinic.modules.clinical.domain.state;

import com.donkan.sisvetclinic.modules.clinical.domain.ClinicalAttention;

public final class WaitingState implements AttentionState {

    public String getName() {
        return "EN_ESPERA";
    }

    public void advance(ClinicalAttention attention) {
        if (attention.getArrivedAt() == null) {
            throw new IllegalStateException(
                "Primero debe registrarse la llegada"
            );
        }

        attention.changeState(new InProgressState());
    }
}
```

### **3.4. InProgressState.java**

```
package com.donkan.sisvetclinic.modules.clinical.domain.state;

import com.donkan.sisvetclinic.modules.clinical.domain.ClinicalAttention;

public final class InProgressState implements AttentionState {

    public String getName() {
        return "ATENDIENDOSE";
    }

    public void advance(ClinicalAttention attention) {
        if (!attention.isClinicalClosed()) {
            throw new IllegalStateException(
                "Falta cerrar la consulta con diagnóstico e indicaciones"
            );
        }

        attention.changeState(
            attention.isRequiresGrooming()
                ? new BathingState()
                : new ReadyForPickupState()
        );
    }
}
```

```
package com.donkan.sisvetclinic.modules.clinical.service.implementation;

import java.text.Normalizer;
import java.util.Locale;
import com.donkan.sisvetclinic.modules.clinical.domain.Actor;
import com.donkan.sisvetclinic.modules.clinical.service.port.out.ActorPort;

public final class ClinicalAccess {

    private ClinicalAccess() {}

    public static Actor require(ActorPort actors, String... allowed) {
        Actor actor = actors.current();
        String actual = normalize(actor.role());

        for (String role : allowed) {
            if (actual.equals(normalize(role))) {
                return actor;
            }
        }

        throw new SecurityException(
            "No tiene permisos para esta operación clínica"
        );
    }

    private static String normalize(String text) {
        return Normalizer.normalize(text, Normalizer.Form.NFD)
            .replaceAll("\\p{M}+", "")
            .replace("ROLE_", "")
            .toUpperCase(Locale.ROOT)
            .trim();
    }
}
```

```
package com.donkan.sisvetclinic.modules.clinical.service.implementation;
```

```
@Service
public class AttentionService implements AttentionUseCase {

    private final AttentionRepositoryPort attentions;
    private final PatientRepositoryPort patients;
    private final ClinicalRecordPort records;
    private final ClinicalChargePort charges;
    private final ActorPort actors;
    private final List<AttentionWorkflow> workflows;

    public AttentionService(
        AttentionRepositoryPort attentions,
        PatientRepositoryPort patients,
        ClinicalRecordPort records,
        ClinicalChargePort charges,
        ActorPort actors,
        List<AttentionWorkflow> workflows
    ) {
        this.attentions = attentions;

        this.records = records;
        this.charges = charges;
        this.actors = actors;
        this.workflows = workflows;
    }

    @Transactional
    public ClinicalAttention registerArrival(ArrivalRequest r) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA", "RECEPTIONIST"
        );

        if (r == null || patients.findById(r.petId()) == null) {
            throw new IllegalArgumentException("Paciente no encontrado");
        }

        ClinicalAttention attention = attentions.findOpenByPet(r.petId());

        if (attention == null) {
            attention = new ClinicalAttention(
                0, r.petId(),
                r.type() == null ? "MEDICAL" : r.type().toUpperCase(),
                null, null, null, "EN_ESPERA", null,
                r.requiresGrooming(), false, null
            );
        }

        attention.markArrived(LocalDateTime.now(), r.requiresGrooming());
        return attentions.save(attention);
    }

    @Transactional
    public void registerUrgency(UrgencyRequest r) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA",
            "RECEPTIONIST", "VETERINARIO", "VETERINARIAN"
        );

        if (r == null || patients.findById(r.petId()) == null) {
            throw new IllegalArgumentException("Mascota inexistente");
        }

        ClinicalAttention attention = attentions.findOpenByPet(r.petId());

        if (attention == null) {
            attention = new ClinicalAttention(
                0, r.petId(), "URGENCY", null, null, null,
                "EN_ESPERA", null, false, false, null
            );
        }

        if (!"EN_ESPERA".equals(attention.getStatus())) {
            throw new IllegalStateException(
                "La urgencia debe registrarse durante la espera"
            );
        }

        attention.registerUrgency(r.description());
        attentions.save(attention);
    }

    @Transactional
    public void assignPriority(long id, int priority) {
        Actor actor = ClinicalAccess.require(
            actors, "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
        );

        ClinicalAttention attention = requireAttention(id);
        attention.assignPriority(priority, actor.id());

        attentions.save(attention);
        attentions.auditPriority(id, actor.id(), priority);
    }

    public List<ClinicalAttention> getWaitingPatients() {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA",
            "RECEPTIONIST", "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
        );

        return attentions.findWaiting();
    }

    @Transactional
    public void startAttention(long id) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "VETERINARIO",
            "VETERINARIAN", "ESPECIALISTA"
        );

        ClinicalAttention attention = requireAttention(id);
        String type = "URGENCY".equals(attention.getType())
            ? "MEDICAL" : attention.getType();

        AttentionWorkflow workflow = workflows.stream()
            .filter(w -> w.supports(type))
            .findFirst()
            .orElseThrow(() -> new IllegalStateException(
                "No existe workflow para " + type
            ));

        workflow.execute(attention);
        attentions.save(attention);
    }

    @Transactional
    public void advanceAttention(long id) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "VETERINARIO",
            "VETERINARIAN", "ESPECIALISTA"
        );

        ClinicalAttention attention = requireAttention(id);

        if ("LISTO_RECOJO".equals(attention.getStatus()) ||
            "ATENDIDO".equals(attention.getStatus())) {
            throw new IllegalStateException(
                "Use el registro de retiro para finalizar la atención"
            );
        }

        attention.advance();
        attentions.save(attention);
    }

    @Transactional
    public void registerPickup(long id) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA", "RECEPTIONIST"
        );

        ClinicalAttention attention = requireAttention(id);

        if (!"LISTO_RECOJO".equals(attention.getStatus())) {
            throw new IllegalStateException(
                "La mascota todavía no está lista para recojo"
            );
        }

        if (attention.getConsultationId() == null ||
            !charges.isSettled(attention.getConsultationId())) {
            throw new IllegalStateException(
                "La atención no tiene cierre clínico o registra cobros pendientes"
            );
        }

        attention.advance();
        attentions.save(attention);
    }

    private ClinicalAttention requireAttention(long id) {
        ClinicalAttention attention = attentions.findById(id);

        if (attention == null) {
            throw new IllegalArgumentException("Atención no encontrada");
        }

        return attention;
    }
}
```

```
                    r.nextDoseDate().atTime(9, 0), null
                )
            );
        }

        return saved;
    }

    @Transactional
    public Referral registerReferral(ReferralRequest r) {
        vet();
        MedicalConsultation consultation = activeConsultation(r.consultationId());

        if (r.reason() == null || r.reason().isBlank()) {
            throw new IllegalArgumentException(
                "Indique motivo de derivación"
            );
        }

        return treatments.saveReferral(
            new Referral(
                0, consultation.id(), r.reason(),
                r.destination(), LocalDateTime.now(), vet().id()
            )
        );
    }

    public java.util.List<MedicationDetail> getMedicationOptions(String search) {
        vet();
        return medications.search(search == null ? "" : search);

            actors, "ADMINISTRADOR", "ADMIN", "VETERINARIO",
            "VETERINARIAN", "ESPECIALISTA"
        );
    }

    private MedicalConsultation activeConsultation(long id) {

        if (consultation == null ||
            "COMPLETED".equals(consultation.status())) {
            throw new IllegalStateException(
                "Consulta no disponible"
```

### **8.6. AppointmentService.java**

Las operaciones de programación y reprogramación emplean aislamiento SERIALIZABLE para proteger la verificación de citas superpuestas dentro de una transacción SQL Server.

```
package com.donkan.sisvetclinic.modules.clinical.service.implementation;

import java.time.LocalDateTime;
import java.time.Duration;
import java.util.List;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Isolation;
import org.springframework.transaction.annotation.Transactional;
import com.donkan.sisvetclinic.modules.clinical.domain.*;
import com.donkan.sisvetclinic.modules.clinical.service.dto.request.*;
import com.donkan.sisvetclinic.modules.clinical.service.port.in.*;
import com.donkan.sisvetclinic.modules.clinical.service.port.out.*;

@Service
public class AppointmentService implements AppointmentUseCase {

    private final AppointmentRepositoryPort appointments;
    private final PatientRepositoryPort patients;
    private final ClinicalRecordPort records;
    private final FollowUpUseCase followUps;
    private final ActorPort actors;
    private final ProfessionalLookupPort professionals;

    public AppointmentService(
        AppointmentRepositoryPort appointments,
        PatientRepositoryPort patients,
        ClinicalRecordPort records,
        FollowUpUseCase followUps,
        ActorPort actors,
        ProfessionalLookupPort professionals
    ) {
        this.appointments = appointments;
        this.patients = patients;
        this.records = records;
        this.followUps = followUps;
        this.actors = actors;
        this.professionals = professionals;
    }

    public List<Appointment> getAvailability(AvailabilityFilter f) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA",
            "RECEPTIONIST", "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
        );

        if (f == null || f.start() == null || f.end() == null ||
            !f.end().isAfter(f.start())) {
            throw new IllegalArgumentException(
                "Rango de consulta inválido"
            );
        }

        return appointments.findAvailability(
            f.professionalId(), f.start(), f.end()
        );
    }

    @Transactional(isolation = Isolation.SERIALIZABLE)
    public Appointment scheduleAppointment(AppointmentRequest request) {
        return create(request, "GENERAL");
    }

    @Transactional(isolation = Isolation.SERIALIZABLE)
    public Appointment scheduleFollowUp(AppointmentRequest request) {
        Appointment appointment = create(request, "FOLLOW_UP");

        followUps.scheduleFollowUp(
            new FollowUpRequest(
                appointment.petId(), appointment.consultationId(),
                "Cita de seguimiento: " + appointment.reason(),
                appointment.startsAt(), appointment.id()
            )
        );

        return appointment;
    }

    @Transactional(isolation = Isolation.SERIALIZABLE)
    public Appointment scheduleSpecialist(AppointmentRequest request) {
        if (request == null ||
            request.specialty() == null ||
            request.specialty().isBlank()) {
            throw new IllegalArgumentException(
                "La especialidad es obligatoria"
            );
        }

        return create(request, "SPECIALIST");
    }

    private Appointment create(AppointmentRequest r, String type) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA",
            "RECEPTIONIST", "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
        );

        if (r == null || patients.findById(r.petId()) == null ||
            r.professionalId() <= 0 || r.date() == null ||
            r.reason() == null || r.reason().isBlank()) {
            throw new IllegalArgumentException(
                "Datos de cita incompletos"
            );
        }

        if (!professionals.canAttend(r.professionalId())) {
            throw new IllegalArgumentException(
                "El usuario no es un profesional clínico activo"
            );
        }

        if ("SPECIALIST".equals(type) &&
            !professionals.hasSpecialty(r.professionalId(), r.specialty())) {
            throw new IllegalArgumentException(
                "El profesional no tiene la especialidad seleccionada"
            );
        }

        int duration = r.durationMinutes() == 0
            ? 30 : r.durationMinutes();

        if (duration < 15 || duration > 180 ||
            !r.date().isAfter(LocalDateTime.now())) {
            throw new IllegalArgumentException(
                "Horario o duración inválidos"
            );
        }

        if (r.consultationId() != null) {
            MedicalConsultation consultation =
                records.findConsultation(r.consultationId());

            if (consultation == null ||
                consultation.petId() != r.petId()) {
                throw new IllegalArgumentException(
                    "Referencia clínica incorrecta"
                );
            }
        }

        LocalDateTime end = r.date().plusMinutes(duration);

        if (appointments.hasConflict(
            r.professionalId(), r.date(), end, 0
        )) {
            throw new IllegalStateException(
                "El profesional ya tiene cita en ese horario"
            );
        }

        return appointments.save(
            new Appointment(
                0, r.petId(), r.professionalId(),
                type + ": " + r.reason(),
                r.date(), end, "CONFIRMED",
                r.specialty(), r.consultationId(),
                LocalDateTime.now(), false
            )
        );
    }

    @Transactional(isolation = Isolation.SERIALIZABLE)
    public void rescheduleAppointment(long id, LocalDateTime date) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA", "RECEPTIONIST"
        );

        Appointment appointment = appointments.findById(id);

        if (appointment == null ||
            !"CONFIRMED".equals(appointment.status()) ||
            date == null || !date.isAfter(LocalDateTime.now())) {
            throw new IllegalStateException(
                "La cita no puede reprogramarse"
            );
        }

        LocalDateTime end = date.plus(
            Duration.between(
                appointment.startsAt(), appointment.endsAt()
            )
        );

        if (appointments.hasConflict(
            appointment.professionalId(), date, end, id
        )) {
            throw new IllegalStateException(
                "El nuevo horario está ocupado"
            );
        }

        appointments.reschedule(id, date, end);
        followUps.rescheduleAppointmentFollowUp(id, date);
    }

    @Transactional
    public void cancelAppointment(long id) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA", "RECEPTIONIST"
        );

        Appointment appointment = appointments.findById(id);

        if (appointment == null ||
            !"CONFIRMED".equals(appointment.status())) {
            throw new IllegalStateException(
                "La cita no puede cancelarse"
            );
        }

        appointments.cancel(id);
        followUps.cancelAppointmentFollowUp(id);
    }
}
```

```
            );

            MedicalConsultation consultation =
                records.findConsultation(r.consultationId());

            if (consultation == null ||
                consultation.petId() != r.petId()) {
                throw new IllegalArgumentException(
                    "Referencia clínica incorrecta"
                );
            }
        }

        return followUps.save(
            new FollowUp(
                0, r.petId(), r.consultationId(), r.reason(),
                r.dueAt(), "PENDING", null, r.appointmentId()

        );

        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN", "RECEPCIONISTA",
            "RECEPTIONIST", "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
        );

        return followUps.findOutstanding();

    public void reviewPendingFollowUps() {
        LocalDateTime now = LocalDateTime.now();

        for (FollowUp followUp : followUps.findPending(now)) {
            Pet pet = patients.findById(followUp.petId());

            if (pet != null && notifications.send(
                pet.ownerId(),
                "FOLLOWUP-" + followUp.id(),
                "Seguimiento clínico",
                followUp.reason()
            )) {
                followUps.markReviewed(followUp.id());
            }
        }

        for (Appointment appointment :
            appointments.findReminderCandidates(now, now.plusDays(1))) {

            Pet pet = patients.findById(appointment.petId());

            if (pet != null && notifications.send(
                pet.ownerId(),
                "APPOINTMENT-" + appointment.id(),
                "Recordatorio de cita",
                appointment.reason()
            )) {
                appointments.markReminderSent(appointment.id());
            }
        }
    }

        long appointmentId,

        followUps.rescheduleByAppointment(appointmentId, date);
    }

    @Transactional

        followUps.cancelByAppointment(appointmentId);
```

```
            Integer.class, species
        );

            jdbc.update(
                "INSERT INTO dbo.ClinicalWeightPolicy " +

            );
```

```
import org.springframework.stereotype.Repository;

import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContextHolder;
import com.donkan.sisvetclinic.modules.clinical.domain.Actor;
import com.donkan.sisvetclinic.modules.clinical.service.port.out.ActorPort;

@Repository
public class SqlActorAdapter implements ActorPort {

    private final JdbcTemplate jdbc;

    public SqlActorAdapter(JdbcTemplate jdbc) {
        this.jdbc = jdbc;
    }

    public Actor current() {
        Authentication auth =
            SecurityContextHolder.getContext().getAuthentication();

        if (auth == null || !auth.isAuthenticated() ||
            "anonymousUser".equals(auth.getPrincipal())) {
            throw new SecurityException("Debe iniciar sesión");
        }

        return jdbc.query(
            "SELECT u.id, r.name AS role_name " +
            "FROM dbo.[User] u JOIN dbo.Role r ON r.id=u.role_id " +
            "WHERE u.username=? AND u.record_status='Active'",
            (r, n) -> new Actor(
                r.getLong("id"), r.getString("role_name")
            ),
            auth.getName()
        ).stream().findFirst().orElseThrow(
            () -> new SecurityException(
                "Cuenta sin permisos vigentes"
            )
        );
    }
}
```

```
package com.donkan.sisvetclinic.modules.clinical.infrastructure.output;

import org.springframework.beans.factory.ObjectProvider;
import org.springframework.stereotype.Component;
import com.donkan.sisvetclinic.modules.clinical.service.port.out.NotificationDispatchPort;
import com.donkan.sisvetclinic.modules.notification.service.port.in.NotificationUseCase;
import com.donkan.sisvetclinic.modules.notification.service.dto.request.NotificationRequest;

@Component
public class NotificationUseCaseAdapter implements NotificationDispatchPort {

    private final ObjectProvider<NotificationUseCase> notifications;

    public NotificationUseCaseAdapter(
        ObjectProvider<NotificationUseCase> notifications
    ) {
        this.notifications = notifications;
    }

    public boolean send(
        long recipientId,
        String key,
        String subject,
        String message
    ) {
        NotificationUseCase useCase = notifications.getIfAvailable();

        if (useCase == null) {
            return false;
        }

        var result = useCase.sendNotification(
            new NotificationRequest(
                recipientId, subject, message, "INTERNAL", key
            )
        );

        return result != null && result.success();
    }
}
```

La clave idempotencyKey permite que Notification identifique una solicitud repetida. Es responsabilidad de ese módulo utilizarla realmente para impedir entregas duplicadas; la presencia del campo por sí sola no garantiza idempotencia.

Si Notification todavía no está implementado, el adaptador devolverá false y Clinical conservará las solicitudes pendientes. No informará falsamente que los avisos fueron entregados.

### **12.7. ClinicalErrorHandler.java**

Este manejador convierte las excepciones comunes del módulo en respuestas HTTP comprensibles. Las restricciones de base de datos no se exponen al usuario como mensajes SQL internos.

```
package com.donkan.sisvetclinic.modules.clinical.infrastructure.input.rest;

import java.util.Map;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.web.bind.annotation.*;

@RestControllerAdvice(
    basePackages = "com.donkan.sisvetclinic.modules.clinical.infrastructure.input.rest"
)
public class ClinicalErrorHandler {

    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<Map<String, String>> invalid(
        IllegalArgumentException exception
    ) {
        return ResponseEntity.badRequest().body(
            Map.of("error", exception.getMessage())
        );
    }

    @ExceptionHandler(IllegalStateException.class)
    public ResponseEntity<Map<String, String>> conflict(
        IllegalStateException exception
    ) {
        return ResponseEntity.status(HttpStatus.CONFLICT).body(
            Map.of("error", exception.getMessage())
        );
    }

    @ExceptionHandler(SecurityException.class)
    public ResponseEntity<Map<String, String>> forbidden(
        SecurityException exception
    ) {
        return ResponseEntity.status(HttpStatus.FORBIDDEN).body(
            Map.of("error", exception.getMessage())
        );
    }

    @ExceptionHandler(DataIntegrityViolationException.class)
    public ResponseEntity<Map<String, String>> integrity(
        DataIntegrityViolationException exception
    ) {
        return ResponseEntity.status(HttpStatus.CONFLICT).body(
            Map.of(
                "error",
                "Operación en conflicto con restricciones de datos"
            )
        );
    }
}
```

### **15.3. PatientUpdateService.java**

Ruta: `clinical/service/implementation/`

```
package com.donkan.sisvetclinic.modules.clinical.service.implementation;

import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import com.donkan.sisvetclinic.modules.clinical.domain.Pet;
import com.donkan.sisvetclinic.modules.clinical.service.dto.request.PetRequest;
import com.donkan.sisvetclinic.modules.clinical.service.port.in.PatientUpdateUseCase;
import com.donkan.sisvetclinic.modules.clinical.service.port.out.*;

@Service
public class PatientUpdateService implements PatientUpdateUseCase {

    private final PatientRepositoryPort patients;
    private final PatientUpdatePort updates;
    private final OwnerLookupPort owners;
    private final ActorPort actors;

    public PatientUpdateService(
        PatientRepositoryPort patients,
        PatientUpdatePort updates,
        OwnerLookupPort owners,
        ActorPort actors
    ) {
        this.patients = patients;
        this.updates = updates;
        this.owners = owners;
        this.actors = actors;
    }

    @Transactional
    public Pet updatePet(long id, PetRequest request) {
        ClinicalAccess.require(
            actors, "ADMINISTRADOR", "ADMIN",
            "RECEPCIONISTA", "RECEPTIONIST"
        );

        if (patients.findById(id) == null) {
            throw new IllegalArgumentException("Mascota inexistente");
        }

        if (request == null || request.ownerId() <= 0 ||
            request.name() == null || request.name().isBlank() ||
            request.species() == null || request.species().isBlank()) {
            throw new IllegalArgumentException(
                "Propietario, nombre y especie son obligatorios"
            );
        }

        if (request.birthDate() == null &&
            (request.estimatedAgeMonths() == null ||
             request.estimatedAgeMonths() < 0)) {
            throw new IllegalArgumentException(
                "Indique fecha de nacimiento o edad aproximada"
            );
        }

        if (!owners.existsOwner(request.ownerId())) {
            throw new IllegalArgumentException(
                "Propietario inexistente"
            );
        }

        Pet changed = new Pet(
            id, request.ownerId(),
            request.name().trim(),
            request.species().trim(),
            request.breed(),
            request.sex(),
            request.birthDate(),
            request.estimatedAgeMonths()
        );

        return updates.update(id, changed);
    }
}
```

### **15.4. SqlPatientUpdateAdapter.java**

Ruta: `clinical/infrastructure/output/persistence/`

```
package com.donkan.sisvetclinic.modules.clinical.infrastructure.output.persistence;

import org.springframework.stereotype.Repository;
import org.springframework.jdbc.core.JdbcTemplate;
import com.donkan.sisvetclinic.modules.clinical.domain.Pet;
import com.donkan.sisvetclinic.modules.clinical.service.port.out.PatientUpdatePort;

@Repository
public class SqlPatientUpdateAdapter implements PatientUpdatePort {

    private final JdbcTemplate jdbc;

    public SqlPatientUpdateAdapter(JdbcTemplate jdbc) {
        this.jdbc = jdbc;
    }

    public Pet update(long id, Pet pet) {
        int affected = jdbc.update(
            "UPDATE dbo.ClinicalPet SET " +
            "owner_id=?,name=?,species=?,breed=?,sex=?," +
            "birth_date=?,estimated_age_months=? WHERE id=?",
            pet.ownerId(),
            pet.name(),
            pet.species(),
            pet.breed(),
            pet.sex(),
            pet.birthDate(),
            pet.estimatedAgeMonths(),
            id
        );

        if (affected != 1) {
            throw new IllegalStateException(
                "No se pudo modificar la mascota"
            );
        }

        return jdbc.query(
            "SELECT * FROM dbo.ClinicalPet WHERE id=?",
            SqlClinicalMappers.PET, id
        ).stream().findFirst().orElseThrow(
            () -> new IllegalStateException(
                "Registro actualizado no encontrado"
            )
        );
    }
}
```

## **16. Integridad referencial con el subsistema comercial**

El SAD V2.0 identifica como pendiente que ClinicalCharge y Sale tienen referencias de consulta que originalmente no podían enlazarse mediante claves foráneas, porque la tabla clínica todavía no existía.

Una vez creada MedicalConsultation, podemos incorporar esas restricciones, pero únicamente después de comprobar que los datos comerciales existentes no contienen referencias inválidas.

Ejecuta el siguiente script por separado, después del anterior.

```
IF NOT EXISTS (
    SELECT 1
    FROM sys.foreign_keys
    WHERE name = 'FK_ClinicalAttention_Consultation'
)
BEGIN
    ALTER TABLE dbo.ClinicalAttention WITH CHECK
    ADD CONSTRAINT FK_ClinicalAttention_Consultation
    FOREIGN KEY (consultation_id)
    REFERENCES dbo.MedicalConsultation(id);
END;
GO

IF OBJECT_ID('dbo.ClinicalCharge', 'U') IS NOT NULL
AND NOT EXISTS (
    SELECT 1
    FROM dbo.ClinicalCharge c
    LEFT JOIN dbo.MedicalConsultation m
        ON m.id = c.consultation_id
    WHERE c.consultation_id IS NOT NULL
      AND m.id IS NULL
)
AND NOT EXISTS (
    SELECT 1
    FROM sys.foreign_keys
    WHERE name = 'FK_ClinicalCharge_MedicalConsultation'
)
BEGIN
    ALTER TABLE dbo.ClinicalCharge WITH CHECK
    ADD CONSTRAINT FK_ClinicalCharge_MedicalConsultation
    FOREIGN KEY (consultation_id)
    REFERENCES dbo.MedicalConsultation(id);
END;
GO

IF OBJECT_ID('dbo.Sale', 'U') IS NOT NULL
AND COL_LENGTH('dbo.Sale', 'consultation_id') IS NOT NULL
AND NOT EXISTS (
    SELECT 1
    FROM dbo.Sale s
    LEFT JOIN dbo.MedicalConsultation m
        ON m.id = s.consultation_id
    WHERE s.consultation_id IS NOT NULL
      AND m.id IS NULL
)
AND NOT EXISTS (
    SELECT 1
    FROM sys.foreign_keys
    WHERE name = 'FK_Sale_MedicalConsultation'
)
BEGIN
    ALTER TABLE dbo.Sale WITH CHECK
    ADD CONSTRAINT FK_Sale_MedicalConsultation
    FOREIGN KEY (consultation_id)
    REFERENCES dbo.MedicalConsultation(id);
END;
GO
```

Estas migraciones presuponen que los tipos de las columnas comerciales coinciden con los de MedicalConsultation.id. Si existen identificadores clínicos antiguos sin correspondencia, el script no agrega la clave foránea correspondiente: primero debe resolverse esa inconsistencia, sin borrar registros automáticamente.

## **19. Flujo operativo implementado**

Con los componentes anteriores, la secuencia prevista es la siguiente:

1. Recepción registra o busca al propietario mediante Commercial y registra la mascota con PatientUseCase.
2. Registra la llegada mediante AttentionUseCase. El paciente queda EN_ESPERA.
3. Cuando existe una urgencia, se registra su descripción y el veterinario determina la prioridad.
4. El veterinario inicia la atención. AttentionService selecciona el workflow adecuado y cambia el estado a ATENDIENDOSE.
5. Consulta, diagnóstico, tratamientos, procedimientos, vacunaciones y derivaciones se registran mediante sus respectivos casos de uso.
6. El veterinario finaliza la consulta cuando existe diagnóstico e indicaciones. El servicio marca el cierre clínico.
7. AttentionService hace avanzar la atención hacia EN_BANO y EN_PELUQUERIA si corresponde, o directamente hacia LISTO_RECOJO.
8. Recepción registra el retiro, verificando el cierre clínico y los conceptos de cobro que correspondan.
9. AppointmentService administra citas, reprogramaciones y cancelaciones. FollowUpService conserva los seguimientos y entrega solicitudes al módulo Notification.

Este es el flujo de las clases implementadas, no una afirmación de que los endpoints ya hayan sido ejecutados contra la base real de producción.

## **20. Corrección final de autorización clínica**

En la revisión de permisos detecté una discrepancia respecto al SRS: un Administrador del sistema no debe quedar automáticamente autorizado para diagnosticar, prescribir o iniciar actuaciones clínicas solo por tener privilegios administrativos.

La autorización de estas operaciones corresponde a VETERINARIO o ESPECIALISTA. Por tanto, estas son las sustituciones definitivas que deben aplicarse en los archivos anteriores.

### **AttentionService.java**

Dentro de los métodos startAttention() y advanceAttention(), sustituye la llamada de autorización inicial por:

```
ClinicalAccess.require(
    actors, "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
);
```

No cambies las autorizaciones de registerArrival(), registerUrgency(), assignPriority(), getWaitingPatients() ni registerPickup(). Cada una representa una operación distinta.

### **ConsultationService.java**

En registerConsultation(), registerDiagnosis(), completeConsultation() y checkWeight(), utiliza únicamente los siguientes roles:

```
Actor actor = ClinicalAccess.require(
    actors, "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
);
```

Para checkWeight(), que no utiliza la variable actor, la llamada es:

```
ClinicalAccess.require(
    actors, "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
);
```

### **TreatmentService.java**

Sustituye el método vet() completo por:

```
private Actor vet() {
    return ClinicalAccess.require(
        actors, "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
    );
}
```

### **WeightPolicyService.java**

En configure(), sustituye la autorización por:

```
ClinicalAccess.require(
    actors, "VETERINARIO", "VETERINARIAN", "ESPECIALISTA"
);
```

Estas correcciones fueron aplicadas al código de comprobación y se volvió a compilar el conjunto con JDK 21.

### **Consideraciones antes de integrar**

Hay tres condiciones que no sería correcto ocultar:

Primero, los adaptadores comerciales suponen exactamente las tablas y columnas documentadas en el SAD V2.0. Hay que contrastarlas con el SQL Server realmente desplegado antes de ejecutar las migraciones.

Segundo, la integración con Notification está completa en cuanto a puertos y adaptador de Clinical, pero el envío real y la garantía de idempotencia corresponden a la implementación del módulo Notification. El código actual no debe considerarse una prueba de que funcionan SMTP, SMS o notificaciones internas.

Tercero, la programación de citas utiliza controles transaccionales de solapamiento, pero la ejecución simultánea de varios schedulers todavía requiere coordinación adicional si SISVET-CLINIC llega a desplegarse en varias instancias.
